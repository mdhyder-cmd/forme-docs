Every destination, considered.

Templates are arranged. Create and connect the actual pages.

Create the page resources

Open Online Store Pages Add page. Enter a title and real content, set visibility, choose the theme template, and save. A theme ZIP supplies templates; it does not create these page records.

Template not in the admin dropdown?

Shopify can base the resource template list on the published theme. Create the page, preview it with the matching template in the unpublished FORME theme, and confirm the assignment when FORME is published. Do this during a controlled launch if the current live theme lacks that suffix.

Lookbook

The lookbook template combines an editorial opening, chapter links, and shoppable looks. In Lookbook chapters, set each block’s title and anchor. Put the same anchor text in the corresponding Shoppable look section. The theme normalizes anchors into URL-friendly IDs. Use a unique anchor for every chapter and select the actual products featured in each look.

FAQ

Add Question blocks with a heading, answer, and category: Shopping, Fit, Delivery, Returns, or Care. Both a question and answer are needed for a row to display. Turn on the FAQ search if useful. Publish your actual delivery and returns terms; sample editorial text is not a store policy.

Story, care, and fit

Use the provided editorial sections and image slots. Replace default headings with your brand voice. In the fit guide, enter verified product measurements and measurement instructions rather than generic size claims. Care instructions must agree with product labels and manufacturer guidance.

Journal and articles

Create a blog and publish articles with featured images. Select the blog in Page destinations and Blog posts sections. Shopify uses the included blog and article templates automatically. Draft articles do not populate the public journal.

Other included templates

Default product, default and two alternate collection templates, collection list, search, cart, password, gift card, article, blog, default page, and 404 layouts are included. The 404 template is used automatically for missing routes; do not create a page named 404 to activate it.
