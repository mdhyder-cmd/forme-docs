Find the right piece.

Native filters, swatches, sorting, and search.

Create useful filters

  1. Install/open Shopify Search & Discovery. Open Filters Add filter.
  2. Start with Availability, Price, Size, Color, and Product type or Category. Choose sources that exist in your catalog.
  3. For visual color filters, use native category/metafield swatch data and enable its visual display in the app.
  4. Reorder filters and values. Remove sources your catalog does not use.
  5. Open a populated collection and a product search. Apply a filter, sort the results, remove a chip, reset, and test browser Back.

FORME displays the filter data Shopify supplies. A filter whose values do not apply to the current collection can be absent. Empty stock, unpublished products, missing option data, or platform collection limits can affect what Shopify returns.

Filter buttons and sorting

The browsing toolbar contains a dedicated filter trigger, an independent sort control, selected-value chips, and a results count. Choose values in the filter panel and apply them. Reset clears the filters while preserving the current sort and, on search pages, the search term.

Sort choices come from Shopify’s native collection or search sort options. Do not expect a collection’s sort list to exactly match search relevance choices.

Search

The header search progressively enhances native storefront search with predictive results. The full results page remains available. Configure result types, synonyms, boosts, and recommendations in Search & Discovery where supported. Search only returns resources that Shopify makes searchable and available.

Recommended catalog consistency

  • Use one Size option naming convention, rather than mixing Size, Sizes, and Garment size.
  • Fill vendor/category fields consistently if you use them as filters.
  • Keep real color names and connect native swatches instead of entering arbitrary color codes in titles.
  • Test a zero-result combination so customers have an obvious way to reset.
