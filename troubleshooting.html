FORME / 0.5.6

A useful place to look.

Common setup issues and the next thing to check.

What you seeWhat to check
An empty homepage product sectionChoose a real collection/product in that section. Check Active status, Online Store availability, collection membership, and market/catalog publication.
All products show sold outCheck each variant’s available quantity at a location that fulfills online orders. Confirm shipping profiles and the selected market. Inventory is not imported by the theme.
A hero model is croppedAdd an independent mobile image; adjust mobile and desktop focal points and desktop vertical position. Preview actual aspect ratios.
Both campaign buttons go to the same editCheck each campaign block’s Department value and Theme settings Departments. Remove unintended URL overrides.
No collection photos in the dropdownUse curated collection blocks with real resources/images, or a merchant submenu whose immediate children are all collection links.
A menu link opens 404Create/publish the resource, select it with the resource picker, and replace hard-coded stale URLs. Template files do not create page records.
A template is missing from a page’s admin selectorThe resource selector can depend on the published theme. Preview the resource in FORME and confirm the assignment at launch.
No fit, care, model, or size-guide detailsCheck the exact metafield keys and types in Product pages, populate their values, and keep the corresponding template blocks.
The FAQ looks emptyEach Question needs a heading, an answer, and a valid category. Clear any active FAQ search.
A lookbook chapter goes nowhereUse the same unique anchor in the chapter block and the corresponding Shoppable look section.
Filters are missingConfigure Search & Discovery filters and populate their source data. Only applicable filter values are returned by Shopify.
A plain text color optionConnect native category/metafield swatch data. A color option name alone does not supply a swatch.
No country/language selectorConfigure multiple available countries/languages in Shopify, publish them, and enable localization in the header/footer.
Currency changes but checkout differsCheck Markets, payment-provider currency eligibility, market catalog, and shipping country. The theme does not control checkout settlement.
Campaign video does not autoplayCheck selected video, browser policies, reduced motion/data-saving preferences, active slide, and visibility. Click Play to verify the video itself.
The Campaign film section is invisibleSelect a Shopify-hosted video. Its empty editor hint is intentionally omitted from the public storefront.
Newsletter/contact message is not receivedVerify store contact/notification settings, consent setup, spam folder, and native form feedback. Test with an address you control.
An app block or payment button is absentEnable the app/embed or block, confirm account/provider eligibility, and test with the app disabled to isolate conflicts.
A drawer feels different after custom codeCompare with a clean unpublished copy. Remove duplicate animation scripts and check the global motion setting and device preferences.
GitHub Pages shows a 404Confirm index.html is at the selected publishing root and deployment completed. See Publishing the handbook.

Report a reproducible issue

Include your FORME version, device/browser, affected template, steps, expected result, actual result, and a redacted screenshot if helpful. Mention app embeds and custom code that affect the page. Use the support guide before sharing access details.
