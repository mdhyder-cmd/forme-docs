FORME / 0.5.6

Leave a clear trail.

Backups, version changes, and safe customization.

Before changing anything

Duplicate the theme in Shopify and download a backup. Record the version, settings, templates, app embeds, and any custom code. Keep a private record of changes and who made them.

Install a new version

  1. Upload the new clean ZIP as an unpublished theme. Keep the current live theme available.
  2. Reapply your theme settings, section media, resource selections, and layout changes. Compare against your recorded configuration.
  3. Re-enable compatible app embeds and review app blocks. Reapply custom code carefully rather than replacing the new version wholesale with old files.
  4. Run your main product, cart, checkout, localization, and contact-form tests.
  5. Publish only after the comparison passes. Keep the previous theme for rollback.

Uploaded third-party themes do not gain a guaranteed automatic-update service. Settings transfer depends on the versions and the update process supplied by the seller. Do not blindly copy all old configuration or template files over a new release.

Code customizations

Prefer the editor’s settings, blocks, and compatible app blocks before editing code. Code changes require a developer and may affect support. Keep upstream library notices. Never put Shopify Admin tokens, payment credentials, or private customer data into theme files.
