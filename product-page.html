Details that earn their space.

A configurable product story, with the purchase always in reach.

Arrange product blocks

Open Products Default product Product information in the theme editor. Drag the blocks into the order you need. The starting composition includes vendor, title, price, options, size-guide link, quantity, buy buttons, pickup, description, fit notes, care, and model notes.

Add a SKU, collapsible row, text, Custom Liquid, or compatible app block where needed. Keep Options and Buy buttons present for normal purchasing. A Featured product section supports the same product-information block system.

  1. Open Settings Custom data Products (some layouts show Metafields and metaobjects). Add the definition with the exact namespace, key, and type above.
  2. Fill the values on each product. For Size guide, select a published page containing the right measurements.
  3. Keep the matching block in the product template and preview that product.

Missing or incorrectly typed fields are omitted. The theme does not invent fit, care, model measurements, or sizing facts. Template block text is shared across products on that template; use metafields for product-specific data.

Options and availability

The selected combination is resolved by Shopify. A product with meaningful options can require an explicit choice before it can be added. “Choose an option” is different from sold out. Set available quantities and price per variant, and verify that an unavailable combination stays unavailable.

Quick add uses the same native product data. Products requiring choices open an options panel rather than silently adding an arbitrary variant.

Accelerated checkout and pickup

In the Buy buttons block, choose whether accelerated checkout is shown. Its payment methods and branding depend on the store, eligibility, and Shopify. Pickup requires a location with online pickup enabled, appropriate inventory, and the pickup block. These controls cannot create payment eligibility or stock.

Gallery and sticky purchase

Product images open the full-screen image viewer, with keyboard navigation where applicable. Videos and 3D media load on request through Shopify’s supported media output. A sticky purchase rail can appear when the main purchase area scrolls away and the Buy buttons block exists.
