FORME / 0.5.6

Make room for your store.

A clean install, with your existing store kept safe.

Upload the theme

  1. Download FORME-0.5.6-clean.zip. Do not upload the documentation ZIP or an outer seller bundle.
  2. Open Online Store Themes. Use Import theme Upload zip file or the equivalent Add theme option.
  3. Select the clean ZIP and wait for Shopify to finish adding it to your theme library.
  4. Open Customize / Edit theme on that theme. Preview your pages before you publish.

Already have a live store?

Duplicate or download your existing theme first. Install FORME as an unpublished theme. Products and collections remain store resources; theme settings and page layouts belong to the individual theme.

Record existing page and product template assignments. A custom template suffix must exist in the published theme to behave as intended on the live store.

What the ZIP does not create

Uploading a theme does not create collections, products, stock, pages, menu entries, app subscriptions, payment methods, translations, or policies. Follow the setup guides to connect each resource.

If Shopify rejects the ZIP

  • Confirm you selected the clean theme ZIP and kept it compressed.
  • The archive must contain assets/, config/, layout/, locales/, sections/, snippets/, and templates/ at its root.
  • Use the original download instead of re-zipping an outer folder on your computer.
  • Record the exact Shopify error and the theme version for support.
