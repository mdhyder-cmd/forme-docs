A clear path to help.

Find the cause, then send the details that matter.

Start with the handbook

Check Troubleshooting first, then test the same resource in a clean, unpublished theme copy. This helps separate theme behavior from product data, apps, and custom code.

What to include

  • Theme name and version.
  • Browser, operating system, device, and viewport.
  • Page/template and the steps needed to reproduce the issue.
  • Expected and actual results.
  • A redacted screenshot or recording if useful.
  • Relevant app embeds and code customizations.

Contact and privacy

Use the private support channel supplied with your purchase for store-specific assistance. For public, non-sensitive theme bugs or documentation issues, the seller can enable the documentation repository’s GitHub Issues.

Do not post passwords, staff invitations, customer details, order exports, payment data, API tokens, or the paid theme source in public issues. Provide any necessary store access through an agreed private support process.

Support scope

The support period, response time, refund terms, installation service, and customization scope are those stated by the seller at purchase. This handbook does not promise a support SLA or include third-party app development. Shopify account, payment, and platform eligibility questions may need Shopify or the provider.
