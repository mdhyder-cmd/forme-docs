An arranged homepage, built around your catalog.

Set the full-screen campaign

  1. Open Home page Full-screen campaign. Keep the two campaign blocks or add up to four.
  2. For each block, upload an image and an independent mobile image. Set the heading, caption, supporting text, and button label.
  3. Choose the campaign destination. The first and second edit use your department settings; Custom uses the block’s link or collection.
  4. Choose an optional featured product. Keep the product connected to the story in that slide.
  5. Enable slide autoplay and choose the interval. Preview manual swiping, arrows, and automatic progression.
Each slide is independent.

Its image/video, text, featured piece, and link change together. Do not assign both edit slides to the same department unless that is intentional.

Make the composition yours

Drag sections to reorder them, hide anything you cannot populate, or add another available section. The default sequence is a starting composition, not a limit of four sections. Use one clear primary heading and keep editorial copy short enough that products remain easy to reach.

Collection and product pickers must select published Shopify resources. Selecting an image does not automatically select products shown in that image.

Hero link priority

For the department slides, the theme first resolves the matching department URL override or selected collection. For a custom destination, use the campaign link or collection. Set every visible button to a deliberate destination and test each slide after saving.
