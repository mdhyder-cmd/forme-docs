Handbook / Build your store

FORME / 0.5.6

A clear way through.

Curated image dropdowns or your own nested Shopify menus.

Curated navigation

  1. Open Theme editor Header and select the curated navigation mode.
  2. Add up to six Collection blocks. Choose a real collection for each block, then optionally override its image or heading.
  3. Choose a featured product for the dropdown. If omitted, the theme can use the first available product from All products.
  4. In Theme settings Departments, select the two collections and edit their labels.
  5. In Theme settings Page destinations, connect your published pages and journal blog. Connected resources populate the curated Explore and customer-care links.

If no collection blocks are connected, the curated dropdown can fall back to up to six store collections. Explicit blocks give you control of the order and imagery.

Use your own Shopify menu

  1. Open Content Menus in Shopify. Create or edit your main menu.
  2. Add parent entries such as Shop or Collections. Nest child links beneath them; third-level links can be nested under those children.
  3. In Header, choose merchant menu mode and select the menu.
  4. To display collection photography, make all the immediate children of that dropdown collection links. Mixed page/product/custom-link children render as a text menu.

Hover, keyboard, and touch

Desktop dropdowns open on hover when a fine pointer is available. Customers can also click the trigger or use keyboard controls. Touch devices use the mobile navigation panel. Keep concise labels and test the path from parent trigger to submenu before launch.

Logo and overlay header

Add the normal logo and a separate light or dark overlay logo in Header. Set logo width and enable the campaign overlay option if you want navigation over campaign imagery. Preview both image backgrounds and scrolled header states for contrast.

Two departments, no special collection names

“For her” and “For him” are editable labels. They can point to any collections you create; the collection handles do not have to be her, him, men, or women. Department URL overrides are available for a different destination.
